# PokiHamster Connector

[中文说明](#中文说明)

PokiHamster Connector is the official Calibre plugin for PokiHamster. It connects your Calibre library with the PokiHamster app.

With PokiHamster, you can use an AI model of your choice to organize ebook content, improve book metadata, and filter advertising, promotional messages, and other irrelevant content.

## Download and Installation

1. Open the [Releases](../../releases) page.
2. Download the latest `PokiHamster-Connector-*.zip` file.
3. Open Calibre.
4. Go to **Preferences → Plugins → Load plugin from file**.
5. Select the downloaded ZIP file. Do not unzip it.
6. Restart Calibre.

The plugin requires the PokiHamster app.

## 中文说明

PokiHamster Connector 是 PokiHamster 的官方 Calibre 插件，用于连接 Calibre 书库与 PokiHamster App。

通过 PokiHamster，你可以借助自己选择或配置的 AI 模型整理电子书内容，改善书籍元数据，并过滤广告、推广信息和其他无关内容。

## 下载与安装

1. 打开本仓库的 [Releases](../../releases) 页面。
2. 下载最新版本的 `PokiHamster-Connector-*.zip`。
3. 打开 Calibre。
4. 进入**首选项 → 插件 → 从文件加载插件**。
5. 选择下载的 ZIP 文件。请勿解压 ZIP。
6. 重启 Calibre。

插件需要与 PokiHamster App 配合使用。
